# UNSEEN EYE — Fine Art & Commercial Photography Studio

> *"I photograph what remains after the moment has passed."*  
> Paris-based photography studio and digital universe.

---

## ✦ Key Features

- **📷 Precision Rangefinder Logo**: Interactive rangefinder emblem with spring-damped shutter button physics, aperture iris rotation, and synchronized eyelid blink mechanics.
- **🗺️ High-Resolution Vector Cartography**: 287 continent vectors, real-time cursor coordinate tracking (`POS: LAT/LNG`), animated geodesic flight routes, and live photograph popovers.
- **🔍 Darkroom Inspection Loupe (3.0×)**: Optical brass inspection magnifier with live film grain inspection, crosshair reticle, and technical EXIF metadata drawer (`[L]`).
- **🖼️ Fine Art Print Room Simulator**: Wall-scale visualization studio with 3 gallery environments (*White Cube, Parisian Salon, Concrete Loft*), 4 museum-grade framing options, and certificate of authenticity reservations.
- **🎞️ Analog Film Stock Engine**: Live real-time emulsion simulation (*Kodak Tri-X 400 B&W, CineStill 800T Halation, Portra 400 Pastel*) with procedural SVG fractal grain overlay (`[M]`).
- **🎧 Generative Ambient Soundscape**: Procedural Web Audio API tape hiss & rain texture generator.
- **⌨️ Pro Command Palette**: Keyboard hotkey navigation (`[?]`, `[T]`, `[M]`, `[L]`, `[F]`, `[Esc]`).
- **🌙 Dark Exhibition Mode**: Luminescent night gallery with high-contrast sodium vapor aesthetics (`/night`).

---

## ✦ Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS v4 + Custom Design Tokens
- **Icons**: Lucide React
- **Audio**: Web Audio API (Native Procedural Synthesis)

---

## ✦ Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
